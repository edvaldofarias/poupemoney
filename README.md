# PoupeMoney

O **PoupeMoney** é um projeto de controle de finanças pessoais criado para auxiliar no acompanhamento e na organização da vida financeira.

O projeto também funciona como ambiente de estudo e experimentação, explorando o uso de inteligência artificial como apoio durante o processo de desenvolvimento de software.

## Tecnologias

A aplicação será dividida em duas partes principais:

- **Backend:** API desenvolvida com .NET, responsável pelas regras de negócio, persistência e disponibilização dos dados financeiros.
- **Frontend:** aplicação web desenvolvida com Angular, responsável pela experiência e interação do usuário.

Cada parte do projeto possui seu próprio README com instruções e detalhes técnicos específicos.

## Estrutura do repositório

```text
poupemoney/
├── backend/    # API .NET
└── frontend/   # Aplicação Angular
```

Para saber mais sobre a API, sua arquitetura, requisitos e execução local, consulte o [README do backend](backend/README.md).

## Objetivo de estudo

Além de desenvolver uma solução para controle financeiro, este repositório busca exercitar práticas de engenharia de software e avaliar como ferramentas de IA podem colaborar em atividades como:

- planejamento e evolução de funcionalidades;
- implementação e revisão de código;
- criação e manutenção de testes;
- documentação técnica;
- análise e melhoria contínua da aplicação.

O uso de IA serve como apoio ao desenvolvimento, mantendo as decisões técnicas, a validação e o aprendizado como partes essenciais do processo.
